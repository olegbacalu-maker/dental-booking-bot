# Что программа умеет сегодня — baseline перед миграцией

Снято **16.09.2026** с версии **1.26.0** (`git describe` → `v1.26.0-2-gc6ed5cf`,
дерево чистое). Это точка отсчёта: после миграции каждая строка обязана
работать так же, иначе миграция не закончена.

⛔ Список составлен **проходом по живой программе и по маршрутам в коде**, а не
по памяти и не по README. Что не проверено — помечено отдельно внизу, а не
записано в зелёные.

## Чем снято

```powershell
# 1. Прогон существующих тестов
.\.venv-desktop\Scripts\python.exe tests\run_tests.py
#    → 1810/1810 прошло за 359.6 с, код выхода 0

# 2. Песочница из исходников
.\.venv-desktop\Scripts\python.exe scripts\dev.py up 8099
#    → http://127.0.0.1:8099/health = {"ok":true,"app":"dentpilot","version":"1.26.0"}

# 3. Обход экранов с куками (пароль песочницы test1234)
```

⚠️ Вход отвергает POST без совпадающего `Origin`/`Referer`
([main.py:561](../bot/app/main.py:561), `same_origin_post`) — первая попытка
входа curl-ом дала 422/403, пока заголовки не были выставлены. Это не помеха
проверке, это **защита от CSRF**, и её надо помнить при смене оболочки.

## Чего НЕ проверял и почему

- [ ] **Собранный exe** — проверялся не мной: дымовой тест `tests/smoke_exe.py`
      вшит в `Build-Installer.ps1` и гоняется при каждой сборке. Отдельного
      прогона в этой сессии не делал.
- [ ] **Установщик Inno Setup** — установки на чистую машину не делал.
- [ ] **Реальное обновление в один клик** — требует выпуска релиза, а
      ⛔ релизы только вперёд и «publish только по слову Олега».
- [ ] **Ветка Postgres** — облако заморожено, её не исполняет ни один набор
      тестов (известно из `CLAUDE.md`, подтверждено: все харнессы поднимают SQLite).
- [ ] **Telegram-бот живьём** — заморожен 08-08, токена в песочнице нет.
- [ ] **Печать на бумагу** — экраны печати отдают HTML, физическую печать и
      совпадение с бланком Anexa 3 глазами не сверял.
- [ ] **LAN с телефона врача** — второй машины в сессии не было.
