# Tauri — оболочка рабочего стола

⏳ **Не начато. Rust на машине не установлен.**

⚠️ Это **последний** шаг и первый необратимый. До него продукт остаётся прежним
exe, а откат — обычный `git revert`. Трезво: окно у программы **уже нативное**
(WebView2 через pywebview, 1280×860, свой заголовок, подтверждение закрытия).
Tauri меняет не «сайт на приложение», а владельца окна. Ощущение приложения
дают экраны без перезагрузки, то есть [frontend.md](frontend.md), а не этот шаг.

## Что заменяется

Вся оболочка — это **339 строк** `bot/desktop.py`.

| Сегодня | Станет |
|---|---|
| `webview.create_window(1280×860, min 960×640, confirm_close)` | `WebviewWindowBuilder` + `CloseRequested` + `prevent_close()` |
| 4 вызова `ctypes.MessageBoxW` | плагин диалогов |
| `webview.settings['ALLOW_DOWNLOADS'] = True` | обработчик загрузки |
| проба `/health` + EXCLUSIVE-бинд | плагин single-instance |
| `os._exit(0)` при закрытии | управляемое гашение сайдкара |

⚠️ **Single-instance меняет поведение продукта.** Плагин **фокусирует**
существующее окно, а сегодня второй запуск открывает **второе** окно к первому
серверу. Решать явно, а не обнаружить у клиники.

⚠️ `ALLOW_DOWNLOADS` проверять поштучно: в движке 10 `FileResponse` и 4 явных
`Content-Disposition: attachment`. Без флага любая ссылка на скачивание —
мёртвая кнопка, и это не видно ни по логу, ни по экрану.

## Окно открывается на адрес движка

```
http://127.0.0.1:<порт>/
```

⛔ Не `tauri.localhost`. Причина — в [architecture.md](architecture.md): кука
`samesite=lax`, `same_origin_post`, `client_is_local`. С чужим origin вход
отвечает 403 ещё до ввода пароля.

## Возможности — минимальный набор

Окно, нативные диалоги, файловая система (только для загрузок), уведомления,
жизненный цикл, запуск и гашение сайдкара.

⛔ Обновлятор Tauri **не включать** — [updates.md](updates.md).

## E2E

Настоящее окно Tauri водится `tauri-driver` + `msedgedriver`, и версия
драйвера обязана совпадать с установленным Edge/WebView2.

⚠️ До появления окна тяжёлый desktop-E2E в CI не заводить: на каждый push
платить холодной сборкой Rust незачем. Порядок ступеней — [release.md](release.md).

## Место на диске

На C: свободно около 16 ГБ, и он переполняется регулярно. Rust с MSVC Build
Tools — это 3–6 ГБ, `target/` — ещё 1–3 ГБ на отладочную сборку.

⛔ `CARGO_HOME` и `RUSTUP_HOME` перенести на D: **до** установки: по умолчанию
они садятся в `C:\Users\<...>\.cargo` и `.rustup`. Сам `target/` окажется
внутри репозитория на D: и уже закрыт в `.gitignore`.
