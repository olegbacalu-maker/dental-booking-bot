# Снятие старого интерфейса

С 21.09 React — продукт по умолчанию, а старые серверные страницы живут как
запасной путь (`clinic.json → ui.react`, `?ui=legacy`). Каждое правило про
экран действует дважды, и это главный множитель сложности. Цель — вычесть
старый интерфейс, оставив то, что серверным остаётся по замыслу: печатные
листы, вход/установку/восстановление/обновление и файловые адреса.

## Что нашлось (119 маршрутов вне `api.py`)

| Вид | Сколько | Судьба |
|---|---|---|
| A — старая страница за `react_on` | 24 (ровно `REACT_SCREENS`) | ветка старой страницы уходит |
| B− — форма/действие только старых страниц | 47 | уходят; у каждого есть `/api`-замена |
| B+ — форма, которой пользуется React или живая страница | 9 | остаются (`/admin/relink`, лицензия, `security/ack`, `telegram/save`, `crypt/confirm`, `migration/confirm`) |
| C — печатный лист | 8 | остаются |
| D — вход, установка, восстановление, обновление, статика | 20 | остаются |
| X+ — файлы и выгрузки, которые зовёт React | 7 | остаются |
| E — серверная страница без React-замены | 2 | **блокируют** снятие каркаса: `/admin/migration`, `/admin/settings/telegram` (+ ветка «бот не активен» у `/admin/qr-print`) |
| F — сироты, ссылок нет | 2 | `/admin/patients.csv`, `/admin/export` (CSV) |

Объём к удалению: ≈5 000 строк Python (~300 КБ, 13,5 % `bot/app`), после
снятия E — ещё каркас `_shell` и `panel.js` (38 КБ). **`panel.css` не уходит:**
его грузит и React (`layout._doc_head`), старым страницам принадлежит ~22 КБ
из 226.

## Главное препятствие — тесты, а не код

`tests/harness.py › _pin_legacy` и `"ui": {"react": []}` во всех четырёх
фикстурах включают СТАРЫЙ интерфейс почти каждому набору: 187 наборов из 323
(46 файлов) открывают A-страницу или шлют форму B−, ещё 41 помощник засева
пишет через B−. То есть сегодня серверный прогон в основном проверяет
интерфейс, которым клиники не пользуются, а React держат наборы API и vitest.
Снимать код раньше, чем тесты переедут, — значит потерять проверки.

Ещё красное, которое придёт само при снятии B−: `test_license_gate`
(`READONLY_ALLOW` в `core/license_state.py` называет `/admin/pin/change`,
`/users/save`, `/lan/save`…), правило демо-списка в `test_structure`
(`core/demo.py` закрывает префиксы `/admin/users/`, `/admin/pin/`,
`/admin/lan/`), `smoke_exe.py` (баннер на `/admin?ui=legacy` и проба
`/slots`) — последний вшит в сборку и уронит `Build-Installer.ps1`.

## Как идём (слово Олега 12.10.2026)
