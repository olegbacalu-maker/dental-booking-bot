## Почему одна папка, а не отдельный репозиторий

⭐ **Флаги требуют одного бинарника.** Переключение экрана флагом в
`clinic.json` происходит **без пересборки**, значит старый интерфейс и новый
лежат в одном `DentPilot.exe`. Два репозитория воюют ровно с этим — а откат без
пересборки и есть то, что делает переход безопасным.

Плюс: версия одна (`engine.py:22`), правка «эндпоинт + экран + переписанные
проверки» остаётся **одним** коммитом, а генератор карты экранов читает `bot/`
и `tests/` вместе.

## Структура

```
frontend/src/
  main.tsx        монтируется в #root, имя экрана берёт из data-screen
  app/            корень клиента
  services/       ЕДИНСТВЕННАЯ точка разговора с движком
  types/          конверт ответа и разбор отказов
  components/     переиспользуемые примитивы
  features/       по предметным областям
  layouts/ hooks/ stores/ utils/
```

⛔ Компоненты в сеть не ходят — только через `services/api.ts`. Иначе разбор
конверта, обработка истёкшей сессии и проверка прав расползутся по сорока
экранам и разойдутся между собой.

## Какой экран рисовать — решает сервер

```html
<div id="root" data-screen="setari-clinica"></div>
```

Это тот же рубильник, что и флаг в `clinic.json`: сервер решает, отдать старую
разметку или узел для React. Клиент про флаг ничего не знает.

## Состояние

Серверное состояние и состояние экрана — разные вещи.

| | Что | Чем |
|---|---|---|
| Серверное | данные пациентов, расписание, справочники | запросы + кеш |
| Экранное | выбранный зуб, открытый диалог, фильтр, вкладка | React state / context |

⏳ Библиотека управления состоянием **пока не добавлена и не нужна**: 41 экран,
состояние в основном серверное. Появится, когда появится причина, а не заранее.

## Оболочка не дублируется

Сайдбар, верхнюю панель, тему, шрифты, класс `anim`, PWA-шапку рисует серверный
`core/layout._shell`. React получает один узел внутри неё.

⛔ Мигрированный экран **никогда не лежит внутри `#live`**. Иначе `panel.js`
через 12 секунд подменит `innerHTML` под смонтированным деревом: карточка
перестанет открываться, перетаскивание умрёт, а в консоли будет пусто.
Правило проверяемое: на странице одновременно не существуют `#root` и `#live`.
