# frontend — React-клиент DentPilot 2.0

Новый интерфейс поверх **существующего** Python/FastAPI движка. Движок —
источник истины для данных, правил, входа, печати и обновлений; здесь только
интерфейс.

## Команды

```bash
npm install          # один раз
npm run dev          # Vite на своём порту, запросы проксируются в песочницу
npm run build        # бандл прямо в bot/app/static/
npm run typecheck    # tsc без вывода файлов
npm run lint         # eslint: рекомендованные правила JS/TS + хуки React
npm test             # vitest, jsdom, только src/**/*.test.{ts,tsx}
```

Иконки: `python scripts/gen_icons.py` пересобирает `src/components/icons.ts`
из `core/layout._I`; `test_structure` краснеет, если файл отстал.

## Как экран попадает к клинике

Сервер решает по профилю: `clinic.json` → `{"ui": {"react": ["settings_clinic"]}}`
(`layout.react_on`). Включён — страница отдаёт узел `#root` с `data-screen`
и серверной заглушкой «интерфейс не загрузился» внутри; выключен — старая
разметка. `?ui=legacy` возвращает старую страницу на один запрос — выход для
регистратуры, если новый экран подвёл. Правка файла руками действует после
перезапуска программы.

Новый экран = имя в `layout.REACT_SCREENS` + ветка в обработчике старой
страницы (`react_on` → `react_shell`, параметры экрана — `data-params`) +
адрес в `FLAG` и строка в `B2` (`scripts/screen_map.py`) + пересборка
`python scripts/screen_map.py` (она пишет `src/app/routes.ts` — маршрут роутера
руками не набирается) + строка в `SCREENS` (`App.tsx`; забытую не пропустит
tsc) + набор `tests/test_<раздел>.py`. Загрузка данных экрана — роутер (B2.2):
экран экспортирует `loadXxx: RouteLoad<T>`, `App.tsx › LOADS` его подключает,
экран читает `hooks/useRouteLoad` (загрузка / готово / отказ / 401 → вход);
`hooks/useLoad` остаётся у экранов, ещё не переехавших. Отказ рисует
`components/LoadFailed`. Любая ссылка в экране — `components/AppLink` (B4):
экран из карты — переход без перезагрузки (оболочку нового адреса приносит
документ этого адреса, `services/doc.ts`), остальное — обычная ссылка, и
решает это `AppLink`. ⛔ Голого `<a href>` в `features/`, `components/`,
`layouts/` нет — держит `test_structure` («ссылки экранов — AppLink»): он
гасил бы всё окно на каждом переходе. Стенд — `python scripts/spa_nav.py`
(нужен Edge).

⚠️ `npm run dev` ждёт, что движок поднят на **8099**:

```powershell
.\dev up 8099
```

⛔ Порт 8088 не использовать — там установленная программа с настоящей
картотекой.

## Три вещи, которые ломаются молча

**1. Имена файлов сборки фиксированы.** Статику отдаёт маршрут
`/static/{kind}/{name}` ([main.py:273](../bot/app/main.py:273)), и он пропускает
только `[a-z0-9_-]+\.{kind}` из `css`, `js`, `fonts`, без вложенных папок.
Обычное имя Vite `index-D4f2Ab9c.js` получает **404**, и страница открывается
пустой без единой ошибки в логе. Проверено: `bundle.js` → 200,
`index-D4f2Ab9c.js` → 404.

Отсюда в `vite.config.ts`: `entryFileNames: 'js/bundle.js'`,
`assetFileNames` → `css/bundle.css`, `inlineDynamicImports: true` (каждый
лишний чанк — ещё одно имя, обязанное пройти шаблон). Кеш при этом
версионируется: адрес несёт `?v=` из `layout._asset_ver()`.

**2. Сборка пишет в каталог движка и НЕ чистит его.** Рядом лежат `panel.css`,
`panel.js`, `index.html` и четыре шрифта. `emptyOutDir: false`, а входная точка
— `src/main.tsx`, а не `index.html`: иначе Vite положил бы свой `index.html`
поверх лендинга бота.

**3. Тема, иконки и тексты — серверные.** Не пересчитывать в TypeScript:

| Что | Где источник | Почему нельзя дублировать |
|---|---|---|
| Цвета | `core/theme.py` → `vars_css()` | подбор `--teal-d` циклом до contrast ≥ 4.5; на зелёной теме по умолчанию `--on-teal` и `--on-teal-d` оба белые, поэтому ошибка невидима разработчику и вылезает у клиники со своим цветом |
| Иконки | `core/layout._I` (76 штук) | `icons.ts` **генерируется**, а не пишется руками |
| Тексты ответов | `core/layout.MSG_BANNER` (90 кодов) | второй словарь в TS = один статус называется разными словами в разных местах; так уже было дважды |

⛔ И общее правило проекта: **ничего графического от Windows.** Вшитый Inter
покрывает четыре подмножества, и в них нет `→`, `◀▶▲▼`, `✔✕`, `⏳`, `−`, `≈` —
они уедут в системный шрифт. Значок = иконка из `_I`, а не символ.

## Граница с движком

```
компонент → services/api.ts → /api/* → FastAPI → db.py
```

⛔ Компоненты в сеть не ходят: только через `services/api.ts`. Там же лежит
разбор конверта `{ok, code, field, data}` и превращение 401/403/409/422 в
разбор по причинам.

⚠️ Адреса **относительные**, базового URL нет. Страницу отдаёт тот же FastAPI,
что и API, поэтому origin один — на этом держатся кука `samesite=lax`,
`same_origin_post` и `client_is_local()`. Захардкоженный `127.0.0.1:8088`
сломал бы LAN и любой порт из `DENTART_PORT`.

## Чего здесь не будет

Печатные документы (043/e, acord, plan-acord, пародонтограмма, анамнеза,
касса, лист восстановления) и аварийные экраны (вход, установка PIN,
восстановление, `CONFIG_BROKEN`, обновление, перезапуск) остаются серверными.
Экран, который обязан открыться, когда бандл не загрузился, не может жить
в бандле.

## Сборка exe

✅ `Build-Desktop.ps1` зовёт `npm ci` (если нет `node_modules`) и `npm run
build` ДО PyInstaller, через `cmd /c … 2>&1`: PowerShell 5.1 при
`ErrorActionPreference=Stop` превращает любой stderr npm в терминирующую
ошибку. Дымовой тест собранного exe (`tests/smoke_exe.py`) требует
`bundle.js` и `bundle.css` из сборки.
